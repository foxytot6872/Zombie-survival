# Audio Assets Directory

This directory contains audio files for the game.

## Required Sound Files

Place the following sound files in this directory (WAV format recommended):

- `build_placed.wav` - Sound when a building is placed
- `turret_fire.wav` - Sound when a turret fires
- `enemy_death.wav` - Sound when an enemy dies
- `building_destroyed.wav` - Sound when a building is destroyed
- `game_over.wav` - Sound when game over
- `wave_start.wav` - Sound when a wave starts
- `wave_clear.wav` - Sound when a wave is cleared
- `upgrade.wav` - Sound when a building is upgraded
- `repair.wav` - Sound when a building is repaired
- `button_click.wav` - Sound when a button is clicked

## Note

If sound files are missing, the game will continue to work without audio. The sound system is designed to gracefully handle missing files.
